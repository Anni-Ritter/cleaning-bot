# Cleaning Bot — Bothost / Polling version

Telegram-бот для ведения очереди уборки между тремя участниками.

Бот умеет:

* вести отдельную очередь для мытья пола;
* вести отдельную очередь для уборки ванной;
* самостоятельно крутить очередь по кругу;
* позволять настроить порядок участников прямо из Telegram;
* менять интервал уборки ванной прямо из чата;
* напоминать об уборке по выходным;
* отмечать задачу как выполненную;
* передавать задачу следующему участнику;
* хранить историю уборок;
* работать через Telegram Long Polling без webhook.

Основной вариант размещения — **Bothost**.

Состояние бота хранится во внешней PostgreSQL-базе, например **Neon**.

## 2. PostgreSQL

Для постоянного хранения данных используется PostgreSQL.

Удобный бесплатный вариант — **Neon**.

После создания проекта Neon выдаст строку подключения примерно такого вида:

```text
postgresql://USER:PASSWORD@HOST/DBNAME?sslmode=require
```

Она будет использоваться как:

```env
DATABASE_URL=postgresql://USER:PASSWORD@HOST/DBNAME?sslmode=require
```

Не публикуй `DATABASE_URL` в GitHub — строка содержит пароль от базы.

В PostgreSQL хранятся:

* очередь мытья пола;
* очередь ванной;
* текущие задания;
* интервал уборки ванной;
* история выполнений и пропусков;
* информация об уже отправленных напоминаниях.

## 3. Переменные окружения

Для работы бота нужны следующие переменные:

```env
LOCAL_MODE=true

BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
CHAT_ID=-1001234567890

USER_1=111111111|Настя
USER_2=222222222|Имя2
USER_3=333333333|Имя3

TIMEZONE=Europe/Moscow

DATABASE_URL=postgresql://USER:PASSWORD@HOST/DBNAME?sslmode=require

BATHROOM_INTERVAL_DAYS=14
```

`BATHROOM_INTERVAL_DAYS` используется как первоначальное значение.

После первого запуска интервал ванной можно менять прямо через Telegram, и новое значение будет храниться в базе.

## 4. Окна напоминаний

Бот не пытается отправить сообщение строго в конкретную минуту.

Вместо этого используются временные окна.

Например:

```env
FRIDAY_ANNOUNCE_START_HOUR=17
FRIDAY_ANNOUNCE_END_HOUR=20

SATURDAY_REMINDER_START_HOUR=10
SATURDAY_REMINDER_END_HOUR=12

SUNDAY_REMINDER_START_HOUR=11
SUNDAY_REMINDER_END_HOUR=13

SUNDAY_FINAL_START_HOUR=17
SUNDAY_FINAL_END_HOUR=20
```

Это означает:

```text
Пятница:
17:00–20:00 — объявление задач на выходные

Суббота:
10:00–12:00 — утреннее напоминание

Воскресенье:
11:00–13:00 — напоминание о незакрытой задаче

Воскресенье:
17:00–20:00 — финальное напоминание
```

Бот проверяет расписание примерно раз в 30 минут.

Если он попал в нужное окно и сообщение этого типа ещё не отправлялось, бот отправит его.

Повторная отправка того же напоминания блокируется через базу данных.

## 5. Настройка очередей

Очереди пола и ванной независимы друг от друга.

Например:

```text
Пол:
Настя → Саша → Катя → Настя → ...

Ванная:
Катя → Настя → Саша → Катя → ...
```

Настроить их можно прямо через Telegram:

```text
/settings
```

В меню доступны:

* 🧹 настройка очереди пола;
* 🛁 настройка очереди ванной;
* 📅 настройка интервала ванной;
* 📊 просмотр текущих настроек.

При настройке очереди нужно выбрать:

1. кто идёт первым;
2. кто идёт вторым;
3. третий участник определяется автоматически.

После выполнения задачи очередь сдвигается по кругу.

---

## 6. Интервал ванной

Ванная не привязана к календарным неделям.

Например, если установлен интервал:

```text
14 дней
```

и ванную отметили выполненной 3 августа, следующая уборка станет актуальна 17 августа.

Если фактически её помыли только 20 августа, следующий срок будет считаться уже от 20 августа.

Интервал можно изменить через:

```text
/settings
```

или командой:

```text
/bathroom_interval 17
```

Можно установить любое значение от 1 до 365 дней.

Основные команды:

```text

```

Показывает краткую информацию о боте.



```text

```

Отправляет тестовое задание, чтобы проверить кнопки и работу очереди.

```text
/setup_floor
```

```text
/setup_bathroom
```

```text
/bathroom_interval
```

Настройка интервала ванной.

Например:

```text
/bathroom_interval 18
```

## 8. Кнопки задач

Когда бот отправляет задание, под сообщением появляются кнопки.

### ✅ Сделано

После нажатия:

* задача записывается в историю;
* текущая задача закрывается;
* очередь соответствующей уборки двигается дальше.

Например:

```text
User1 → User2 → User3
```

после выполнения User1 превращается в:

```text
User2 → User3 → User1
```

### ⏭️ Пропускаю очередь

Если текущий участник не может выполнить уборку:

* пропуск записывается в историю;
* очередь двигается;
* задача передаётся следующему человеку.

## 9. Локальный запуск

Для локального запуска рекомендуется Python 3.11+.

Создай виртуальное окружение:

### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Создай файл `.env` и заполни переменные.

Если Telegram на компьютере доступен только через системный VPN-прокси, можно добавить:

```env
BOT_PROXY=http://127.0.0.1:7890
```

Для использования proxy в зависимостях должен быть установлен:

```text
aiohttp-socks
```

Запуск:

```powershell
python app.py
```

При успешном запуске появится примерно:

```text
Bot started in polling mode
Background cleaning scheduler started
```

После этого можно проверить в Telegram:

```text
/status
```

или:

```text
/test
```

## 10. Размещение на Bothost

Для Bothost используется **Long Polling**.

Webhook не требуется.

В Bothost нужно:

1. создать нового бота;
2. подключить GitHub-репозиторий;
3. выбрать ветку `main`;
4. указать главный файл `app.py`;
5. добавить Environment Variables;
6. запустить приложение.

Команда запуска:

```text
python app.py
```

На Bothost должно быть:

```env
LOCAL_MODE=true
```

### Proxy на Bothost

Переменную:

```env
BOT_PROXY=http://127.0.0.1:7890
```

на Bothost добавлять **не нужно**.

Она используется только при локальном запуске через VPN-прокси на компьютере.

На сервере бот подключается к Telegram напрямую.

## 11. GitHub

Создай приватный GitHub-репозиторий, например:

```text
cleaning-bot
```

И выполни в папке проекта:

```bash
git init
git add .
git commit -m "Initial cleaning bot"
git branch -M main
git remote add origin https://github.com/YOUR_LOGIN/cleaning-bot.git
git push -u origin main
```

Перед `git add .` обязательно проверь `.gitignore`.

Пример:

```gitignore
.env
.venv/
__pycache__/
*.pyc
cleaning.db
```

Токен Telegram и пароль PostgreSQL не должны попадать в GitHub.

---

## 12. Обновление бота

После изменений:

```bash
git add .
git commit -m "Update cleaning bot"
git push
```

Если Bothost подключён к GitHub с автоматическим деплоем, новая версия бота будет загружена после push.

Данные очередей и история при этом останутся в PostgreSQL.
